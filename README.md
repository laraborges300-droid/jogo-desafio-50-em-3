# 50 Países em 3 Minutos

Um jogo de conhecimentos geográficos no qual o jogador precisa citar 50 países em apenas 3 minutos!

**[Jogue agora!](https://laraborges300-droid.github.io/jogo-desafio-50-em-3/)**

## Sobre o projeto

O desafio consiste em digitar o nome de 50 países antes que o cronômetro chegue a zero. O jogo valida as respostas automaticamente e contabiliza os países encontrados.

## Funcionalidades

- Desafio de 50 países em 3 minutos.
- Validação automática das respostas.
- Identificação de países já encontrados.
- Contador de pontuação.
- Cronômetro regressivo.
- Opção de desistir e reiniciar a partida.
- Ranking geral de jogadores.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vite
- Supabase
- GitHub Pages

## Publicação

O projeto está hospedado no GitHub Pages, com publicação automatizada por meio do GitHub Actions.

Cada atualização enviada para a branch `main` inicia um novo processo de compilação e publicação.
